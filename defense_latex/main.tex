\chapter{Experimental Evaluation}

\section{System}
Spara (\texttt{gsplit}) is an efficient distributed GNN training system built on
top of the Deep Graph Library (DGL). It introduces \emph{partition-aware
sampling} and \emph{feature loading} to reduce cross-GPU communication during
multi-GPU graph neural network training. Each GPU owns a partition of the graph
(a METIS partition weighted by sampling frequency); sampling, feature caching,
and the model forward/backward exchange only boundary data across GPUs via NCCL.

\section{Experimental Setup}
All experiments were run on \textbf{RunPod} using a node with
\textbf{2$\times$ NVIDIA A100-SXM4-80GB} GPUs (NVLink/NVSwitch). The software
stack is \textbf{CUDA 12.4}, \textbf{PyTorch 2.4 (cu124)}, and a custom build of
\textbf{DGL} containing the Spara C++/CUDA operators.

We evaluate the \texttt{split} (Spara) system on OGB node-classification graphs
with a GraphSAGE model (hidden size 256, batch size 1024). The neighbor
\textbf{fanout is 15 per layer}, and we sweep the number of sampling layers
(depth) over $\{3,4,5\}$. Results below use \textbf{2 GPUs} (\texttt{world\_size}
$=2$) with the corresponding 2-partition map
(\texttt{\_w2\_ndst\_efreq\_xbal}), real OGB features, and the partition-aware
split dataloader in UVA mode. Partition maps for both 2 and 4 partitions are
generated and archived; the 4-GPU runs are future work.

All timings are \textbf{per-epoch averages}; GPU memory is the peak allocated;
test accuracy is reported from the partition-local evaluation on rank~0.

\section{Discussion}
Across both graphs, per-epoch time grows with sampling depth as the sampled
subgraph (edges computed) expands super-linearly: on papers100M, going from 3 to
5 layers grows edges computed from $58$\,M to $802$\,M and epoch time from
$\sim$21\,s to $\sim$128\,s. Neighbor sampling dominates the per-step cost at
every depth, while feature-loading time stays small until depth~5 on
papers100M, where the working set no longer fits the on-GPU feature cache and
more features are gathered from host memory over UVA. Test accuracy is stable
across depths ($\sim$55\% on arxiv, $\sim$45\% on papers100M in a short run),
confirming the pipeline trains correctly on real features.
